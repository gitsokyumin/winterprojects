# winterprojects
겨울방학 코딩실력 향상 프로젝트 _ 성규민

**1. Django를 이용한 웹사이트 제작과정 학습을 통한 뉴스 컨텐츠 웹사이트 제작 및 리뷰 사이트 제작**(이 페이지) --> 스태틱 전까지 진행

**동기** : 1년 중 대부분을 파이썬의 기초 문법을 공부하며 지내어 그 이외의 것을 할 기회가 많지 않았음.
2024 코드엑스의 목표였던 뉴스 웹사이트 개발을 통한 교내 타 신문 동아리(더프레스, TOP)와의 협업도 부원들의 성실성과 의지 부족으로
인해 진전되지 않은 상황.

**목표** : 이에 직접 <점프 투 장고>에 나와있는 Django 프레임워크를 활용한, 간단한 웹사이트 제작 예제를 참고하며 
기존 프로젝트를 완성시키기 위해 노력함과 동시에, 금년에 진행할 급식 시스템 문제 개선 프로젝트의 기초가 될 수 있는 ‘급식리뷰’ 사이트 
제작 및 게시를 목표로 함. 

**기간** : 1월 중

**결과물** : 뉴스를 업로드할 수 있는 웹페이지 1개, 특정 메뉴에 대한 리뷰를 사용자가 직접 작성할 수 있는 웹페이지 1개

**2. 자바스크립트 학습을 통한 게임 제작 또는 구글 확장 프로그램 제작해보기**

**동기** : 모든 프로그래밍 언어로 게임을 만들 수는 있지만 파이썬은 게임 제작에 적합한 언어는 아님. 
계속 이렇게 한 가지 언어만 배우는 것에도 결국에는 한계가 있으므로 가장 활용성이 높은 언어 중 하나라고 할 수 있는 
자바스크립트(javascript) 언어를 배우고 이를 활용한 게임을 만들거나 구글 확장 프로그램을 제작해보고자 함.


**목표** : 자바스크립트 언어의 기초를 조금 다진 후, 코드엑스 동아리를 홍보할 때 써먹을 수 있는 게임을 하나 만들거나, 
참신한 아이디어를 통해 크롬 브라우저에서 실제로 사용 가능한 확장 프로그램을 간단하게라도 제작해보는 것을 목표로 함. 
게임은 크롬 공룡 게임을 참고하며, 그 수준으로 단순하게 만들 것. 특히 게임을 만든다면 게임에 들어갈 사운드를 만들기
위해서 미디 방식을 통한 게임 사운드 디자인에 주력하여 이를 결과물에서 부각할 예정.

**기간** : 2월 중

**결과물** : 자바스크립트를 통해 제작한 게임 또는 구글 크롬 확장 프로그램

**3. 파이썬 딥러닝을 통한 액티브 노이즈 캔슬링 구현**

**동기** : 1학년 수학 교과에서 액티브 노이즈 캔슬링의 원리에 삼각함수가 활용된다는 내용의 탐구를 진행했었음. 사용되는 양상만 언급한 것이지 실제로 어떻게 돌아가는지에 대해서는 깊게 탐구하지 않았기 때문에 실제로 노이즈 캔슬링을 파이썬을 통해서 완벽하진 않더라도 구현해보고자 함. 

**목표** : 파이썬 딥러닝 라이브러리 활용법에 대해 조금 익힌 후, 이를 활용해 실제 마이크 입력값을 실시간으로, 혹은 녹음 파일의 역위상을 바로 생성해내는 프로그램을 제작하는 것이 목표임. 

**기간** : 2월 중

**결과물** : 노이즈 캔슬링을 수행하는 딥러닝 알고리즘
